# OMAN: THE DARK SIDE — Art Phase 3
The Omani character collection (20 separate characters)

Each character is **one separate image**: full body, neutral background, so it can serve as a character reference. Never a group shot.

## How to use
1. **Copy a character's prompt,** and replace `[SHEET]` with the shared ending below.
2. **When you get a face you like,** save it. Use it as a reference (`--oref` / Character Reference) for every later image of the same character: side view, back view, and in-game scenes.
3. **For side and back views,** take the prompt and replace `FRONT VIEW` with `SIDE PROFILE VIEW` or `BACK VIEW`, using the same reference.
4. **Check the cultural checklist at the end** before keeping any image.

**[SHEET]** (shared ending):
```
full body character reference, FRONT VIEW, standing in a relaxed natural pose, plain neutral mid-grey studio background, soft even studio lighting with subtle rim light, feet visible, realistic skin texture and natural asymmetry, natural human proportions, photorealistic AAA video game character render, Unreal Engine 5 quality, high detail, sharp focus --ar 2:3 --style raw --no text, letters, watermark, cartoon, anime, plastic skin, distorted hands, fantasy costume, turban styles from other countries
```


## Cultural checklist (every character image)
- [ ] **Men's dishdasha:** collarless, ankle-length, with a single neck tassel (furakha). No Saudi or Emirati collar or cuff.
- [ ] **Kumma:** a round embroidered cap. **Mussar:** a wrapped turban. Never a red-and-white ghutra with an agal.
- [ ] **Khanjar:** formal occasions only. Not on everyday characters.
- [ ] **Women:** dignified and modest, not exoticised. Have an Omani woman review the traditional regional outfits (characters 13 and 14) before use.
- [ ] **Police, hospital and government:** fictional uniforms and badges only, with no real logos.
- [ ] **Workers and residents of every background:** realistic and respectful, never comic.
- [ ] **Supernatural beings:** stay ambiguous. Never present a real religious or folk belief as a monster.
