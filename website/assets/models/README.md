# Character model

`xbot.glb` is the "X Bot" character from the three.js examples (MIT-licensed repository).
It is a Mixamo character with Mixamo animations (idle, walk, run, agree, headShake).
Mixamo's terms allow use inside games and projects; they do not allow redistributing the raw files as a standalone asset pack.
The Omani clothing (dishdasha, kumma, mussar, abaya, uniform) is added in code in `harat/harat.js`.
Replace this file with a real Omani character later (for example a MetaHuman export) without changing the game code.
