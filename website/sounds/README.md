# Real recordings (optional)

Put audio files here and list them in `manifest.json`, for example:
```json
{ "files": ["wind.mp3", "night.mp3", "clue.mp3", "page.mp3", "whisper.mp3", "steps.mp3"] }
```

| File | What to record |
|---|---|
| `wind.mp3` | 30–60 s of night wind in an open place, loopable |
| `night.mp3` | 30–60 s of night insects in a palm grove, loopable |
| `clue.mp3` | A short soft sound for finding a clue (under 1 s) |
| `page.mp3` | A paper page turning (under 1 s) |
| `whisper.mp3` | 3–4 s of an unclear whisper. Not real words, recorded by a volunteer |
| `steps.mp3` | 4 slow footsteps on a tiled floor in an empty room |

A phone is enough. Record on a quiet night, and only in public places or with permission.
